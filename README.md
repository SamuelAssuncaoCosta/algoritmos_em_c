# Algoritmos em C

Repositório dedicado aos exercícios e práticas desenvolvidos durante meus estudos de **Ciência da Computação**, utilizando a linguagem C.

O objetivo é desenvolver e consolidar conhecimentos em lógica de programação, estruturas de dados e resolução de problemas.

## 📚 Conteúdos estudados

Os exercícios estão organizados em pastas de acordo com os assuntos praticados:

- Estruturas de repetição
- Vetores e matrizes
- Funções
- Ponteiros
- Alocação dinâmica de memória
- Manipulação de arquivos
- Strings
- Structs
- Algoritmos de ordenação, como Bubble Sort

## 🛠️ Tecnologias utilizadas

- Linguagem C
- Git
- GitHub

## 📁 Organização

Os arquivos estão separados em diretórios conforme os conteúdos estudados, facilitando a consulta e o acompanhamento da evolução dos exercícios.

## 🎯 Objetivo do repositório

Registrar minha evolução no aprendizado de programação, praticar a resolução de problemas e construir uma base sólida em lógica de programação e linguagem C.

*Repositório em constante atualização conforme avanço nos estudos.*
